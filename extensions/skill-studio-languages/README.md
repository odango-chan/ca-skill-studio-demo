# SKILL Studio YAML/Python syntax extension

Declarative TextMate grammars and language configurations for the online Theia host. No LSP, diagnostics, execution, or runtime network dependency.

Vendored unchanged from [microsoft/vscode](https://github.com/microsoft/vscode/tree/9587121db4909cbd295d160a633c8f1067ac30b8/extensions) at commit `9587121db4909cbd295d160a633c8f1067ac30b8`. Upstream dependencies: YAML from [RedCMD/YAML-Syntax-Highlighter](https://github.com/RedCMD/YAML-Syntax-Highlighter) (MIT), Python from [MagicStack/MagicPython](https://github.com/MagicStack/MagicPython) (MIT). See the vendored `upstream/*/cgmanifest.json` attribution and upstream `LICENSE.txt`. No modifications to their grammar content.

Bundled only as a Theia built-in VS Code extension; do not confuse syntax tokenization with Language Server features.
