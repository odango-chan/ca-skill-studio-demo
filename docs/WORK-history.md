## 2026-11-18 · AI Procedure Authoring P1（Go Gateway 集成）

[Issue #200](https://github.com/odango-chan/ca-skill-studio-demo/issues/200) · [Canonical design](design/ai-procedure-authoring.md) · [Go AI Gateway](https://github.com/odango-chan/ai-gateway) · [Gateway browser CORS issue #4](https://github.com/odango-chan/ai-gateway/issues/4)

- **产品边界：** 独立 AI Authoring Editor Tab；模型只输出不可信语义提案；Host 负责 Context Pack、ModelProposal 校验、Change Set、v1alpha5 Patch 和原生 TextDocument Buffer。用户自行保存；不执行 Runtime / Tool。
- **语言基线：** CA-SL v1alpha5 已 FROZEN / RELEASED（`ca-skills@0abfd0e1ab99f481a4ae01f3f47efc54783dd5e5`）；IngressCatalog v1alpha1 已发布（`ca-skills@9412be9894ef36acf846c757a5870dc0c48b33ac`）。v1alpha4 不作为编辑或兼容路径。
- **Gateway：** 使用独立 Go 仓 `odango-chan/ai-gateway`，透明转发 OpenAI-compatible HTTP，不做 Prompt 处理、Model 选择、协议转换或用户管理。Gateway 部署在本机 loopback 或可信内网服务器；Provider API Key 只保存在 Gateway 主机。
- **请求契约：** Studio 的 `gatewayUrl` 是带 upstream label 和上游 path prefix 的路由前缀，例如 `http://127.0.0.1:8787/opencode-go/openai`；Client 追加 `/v1/chat/completions`。Model ID 由 Studio 应用设置提供（初始默认 `deepseek-v4.1-flash`），并放入请求体；Host 生成稳定 `X-Opencode-Session`。
- **访问边界：** loopback 不需要 Gateway token；非 loopback 使用部署级共享 `X-Gateway-Token`，不是用户认证或用户身份。Host SecretStorage 保存该共享 token；Provider Key 不进入浏览器、Webview、VSIX、工作区或 Context Pack。请求不携带 Cookie。
- **浏览器跨域：** Gateway 当前默认不启用 CORS；GitHub Pages / Theia Browser-Only 调用本地或内网 Gateway 需要精确 Origin allowlist 和 Private Network preflight 支持，跟踪于 [ai-gateway #4](https://github.com/odango-chan/ai-gateway/issues/4)。CORS 不是认证。
- **实现 PR 顺序：** [#201 Design](https://github.com/odango-chan/ca-skill-studio-demo/pull/201) → [#203 Authoring Core](https://github.com/odango-chan/ca-skill-studio-demo/pull/203) → [#204 Change Set](https://github.com/odango-chan/ca-skill-studio-demo/pull/204) → [#207 v1alpha5 Patch Engine](https://github.com/odango-chan/ca-skill-studio-demo/pull/207) → [#208 Editor Tab](https://github.com/odango-chan/ca-skill-studio-demo/pull/208)。旧 [#206 Worker prototype](https://github.com/odango-chan/ca-skill-studio-demo/pull/206) 已废弃，不得合并。
- **当前状态：** Core、Change Set、Patch Engine、Editor Tab 均有实现；Go Gateway 独立仓已存在。Studio → Gateway 真实浏览器 / 模型请求尚未验收；CORS issue #4 未完成。所有 Apply 继续关闭，直到集成的已发布 v1alpha5 Compiler 对同一候选返回完整权威 PASS；Compiler PR #38 仍为 `CANDIDATE_PARTIAL`。
- **验收纪律：** 本轮刷新会产生新的 PR head，旧 exact-head CI 不能代替新 head 验收；每个 PR 必须重新运行对应单测、IDE Host、Theia Browser Host / Browser-Only Chromium 检查。

## 2026-11-13 · Theia-only baseline and Classic retirement

**Historical baseline at this checkpoint:** `347b80682fa3f9044246a140a3b9ae5856095658`. VS Code Web Extension hosted by Theia 1.76 browser-only is the sole workbench. [PR #186](https://github.com/odango-chan/ca-skill-studio-demo/pull/186) is merged; Classic standalone browser app, build scripts, CI path and Pages fallback are removed. Resulting-main Pages deployment [run #43405949805](https://github.com/odango-chan/ca-skill-studio-demo/actions/runs/43405949805) succeeded. Its build-info records `sourceSha` and `workflowSha` as `347b80682fa3f9044246a140a3b9ae5856095658`, `defaultHost: theia-browser-only`, and `classicPublished: false`.

### 当前 Theia 实现

- **Package Explorer:** native Explorer container combines Skills and Plugin-managed Dependencies. Native Files remains available. Dependency Service owns acquisition, immutable snapshots and Lock state. Build Artifacts remain hidden until the Compiler supplies a real BuildResult.
- **Native Markdown:** pinned vscode.markdown-language-features@1.95.3 owns Theia rendering and Preview lifecycle. Studio contributes shared preview theme and exact Package-local link/security policy. Native bidirectional scroll preferences are enabled; actual editor/preview scroll synchronization remains a manual inspection item until real user scrolling is verified.
- **Inspector / Data Flow:** Legacy Producer / Consumer Data Flow lives in the right-side Inspector; PR #197 adds a v1alpha4 source-only Data Flow projection for Context, stage arguments, Predicate parameters and declared Evidence requirements. The standalone Evidence view/provider is retired. Runtime Evidence remains NOT_RUN.
- **Skill Language:** editor language features pin the frozen CA-SL v1alpha4 source in ca-skills. LSP / Designer source projection is not Compiler linking or qualification; Compiler Check/Build remains authoritative.
- **Examples:** 5GC establish-pdu-session and MAS establish-pdu-session-mas v1alpha4 are separate, separately selectable Skill packages. Example project assembly and source acquisition are being moved toward build-time, version-pinned authoritative repository inputs; Studio-local copies must not become a second contract authority.

### Classic retirement boundary

PR #186 has removed the Classic standalone browser app, root-level build entrypoint, Classic shell icon CSS injection, old Classic-only E2E runner, and the /classic/ Pages artifact. Shared parser, projection, icon geometry, Package fixtures and edit-policy modules remain only where consumed by Theia, its extensions or regression tests. No user workspaces or user-authored Skill files were deleted.

### 后续产品基础设施（尚未作为已交付能力）

- Empty workspace Welcome: New Project, Open Project and explicitly selected Example project; do not auto-load an Example into a project-less workspace.
- Build-time Example acquisition from authoritative repositories with pinned refs and explicit file ownership.
- Unified Contract Acquisition for Skill / Host / Tool schemas; LSP, Completion, Hover, Definition, References, Diagnostics and Semantic Tokens consume the resolved project contract snapshot.
- Help menu links to current Chinese Skill Language specifications and authoring guides; localization uses VS Code Locale with zh-CN and en resources, without a second language setting.
- Online Theia and desktop VS Code consume the same extension resources and language services.

### 运行边界

GitHub Pages uses browser-only Theia with same-origin Webviews. It is suitable for public examples and non-sensitive workspaces only. Browser storage is not local disk or GitHub synchronization. The host does not execute user Python, Skill Runtime, Agent, Provider or real 5GC operations. No Runtime / Provider / MAS / 5GC qualification is claimed.
