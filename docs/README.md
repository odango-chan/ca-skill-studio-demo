## 文档状态约定

- **Confirmed**：已由用户明确确认或由当前源仓事实直接确定。
- **Proposed**：设计建议，尚待用户确认。
- **Open**：需要补充信息或明确决策。
- **Deferred**：明确推迟，不属于当前阶段。
- **Observed**：从当前 Demo 源文件或实现中直接观察到的事实。

不要把 Proposed / Open 内容写成已实现事实。
