## Evidence status vocabulary

- `MERGED`: PR is merged; this alone does not imply deployment or later-SHA acceptance.
- `DEPLOYED`: Pages reports the exact source SHA and the deployment workflow succeeded.
- `PASS`: a named gate passed on the exact SHA stated.
- `NOT_RUN`: the named test or environment was not executed.
- `BLOCKED`: execution could not proceed for a stated prerequisite / infrastructure reason.
- `NOT_QUALIFIED`: no Runtime, Owner, Host, Integration, 5GC or Production qualification claim.

Do not copy historical PASS to a new main or PR head. Unit, mock, static, clean-profile-only or deployment PASS must not imply a different acceptance scope.
